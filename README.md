# Physics Simulations

Interactive simulations for General College Physics, published with GitHub Pages.

- Catalog page: `index.html`
- Each simulation: `sims/chNN-short-name/index.html` (one self-contained file, no external libraries)
- Chapter and section numbers follow OpenStax *College Physics 2e*.

## Adding a simulation

1. Upload the new folder (containing its `index.html`) into `sims/`.
2. Paste its catalog card into `index.html` below the line `ADD NEW SIMULATION CARDS BELOW THIS LINE`, in chapter order.
3. Commit. The site updates in about a minute.
